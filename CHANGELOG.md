# Changelog

All notable changes to renpy_cue are documented here.

## [0.1.0] - 2026-08-26

First release.

### Added
- SFX and Music libraries with user-configurable external folders.
- Marker editing, replay tracking, and intensity groups.
- Import/Export sharing: portable `.zip` bundles with baked external-media refs.
- Shared cross-game data folder, keybinds, auto-backups, and About page.
